https://weiyan-shi.github.io/

Edit homepage content in `components/`, metadata in `_templates/homepage.html`,
and the theme in `brat.css`. Then run `python3 scripts/build_homepage.py` before
committing. Commit the generated `index.html` and `sitemap.xml` with the sources.
The published homepage includes all content in HTML; JavaScript only adds interactions.

The green apple favicon uses the Lucide apple icon. Attribution and license are
in `images/icons/`.
